Konomi Examples

AI Conversation Assistant

Create an AI assistant that helps with different topics:

let topic = "quantum physics"
try {
    let response = ask "Explain " + topic + " in simple terms"
    if (response.length > 200) {
        ask "Can you give me a shorter explanation?"
    }
} catch {
    ask "Let's try something simpler instead"
}
Smart Calculator

Perform calculations and get AI explanations:

let num1 = 42
let num2 = 8
let result = num1 / num2

if (result > 5) {
    ask "Explain why " + num1 + " divided by " + num2 + " equals " + result
}
Dynamic Story Generator

Generate interactive stories based on user input:

let character = "space explorer"
let setting = "distant galaxy"

try {
    let story = ask "Create a short story about a " + character + " in a " + setting
    if (story.length > 150) {
        ask "That was great! What happens next?"
    }
} catch {
    ask "Tell me a different story about " + character
}
