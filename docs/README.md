## Quick Start

Konomi provides a simple way to interact with AI models:

```konomi
let greeting = "Hello, AI!"
ask greeting

let age = 25
if (age >= 18) {
    ask "What are some good career options?"
} else {
    ask "What subjects should I study?"
}
```
